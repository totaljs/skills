# 22. SEO recipes

All SEO is rendered on the server — crawlers and AI get finished HTML.

### One function for `<head>`

A single controller function, `Func.head($, type, model)`, builds for every page type:

- `<title>` (≤ 60 characters), `meta description` (cut by `shorten()` to 160 characters at word boundaries),
- `meta robots` — `index,follow,max-image-preview:large` / `noindex,follow` for search results,
- `link rel=canonical` (always from `CONF.url`),
- `link rel=prev/next` for pagination,
- Open Graph and Twitter Card,
- JSON-LD.

All values go through `.encode()`, JSON-LD through:

```js
function jsonld(value) {
	return '<script type="application/ld+json">' + JSON.stringify(value).replace(/</g, '\\u003c') + '</script>';
}
```

(`<` is escaped so that text containing `</script>` can't close the script.)

### JSON-LD by page type

| Page | Types |
|---|---|
| homepage | `WebSite` (+ `SearchAction`), `CollectionPage` with `ItemList` |
| pagination | `CollectionPage` |
| detail | a type matching the content (`Article`, `Product`, `SoftwareSourceCode`…), `BreadcrumbList` |
| static page | `TechArticle`, `BreadcrumbList` |

### Rules that proved useful

- **Unique descriptions:** if a description isn't distinctive, prepend the item name (`name + ': ' + description`).
- **One `<h1>`** per page; if a section has no heading, add a hidden `<h2 class="sr">` (no skipped levels).
- **Search results** = `noindex,follow` (not indexed, but links are followed).
- **Invalid parameters** (`?page=99`, `?page=abc`) = a real **404**, not an empty list.
- **Non-canonical URLs** = 301 to the canonical one.
- **Helper URLs** (previews, downloads) = `X-Robots-Tag: noindex` and a link with `rel="nofollow"`.
- **Images** have `width`/`height` and `alt`; the first one gets `fetchpriority="high"`, the rest `loading="lazy"`.

### sitemap.xml and robots.txt generated by code

```js
ROUTE('FILE /sitemap.xml', sitemap);
ROUTE('FILE /robots.txt', robots);

function robots($) {
	$.response.minify = false;
	$.text('User-agent: *\nAllow: /\nDisallow: /download\nDisallow: /admin/\n\nSitemap: ' + hostname($) + '/sitemap.xml\n');
}
```

`Disallow: /download` (without a trailing slash) covers `/download/`, `/download.js` and `/download.css`.

### For AI search engines

- `public/llms.txt` — a short description of the project with links to the documentation,
- `<link rel="alternate" type="text/plain" href="/llms.txt" />` in the layout,
- robots.txt doesn't block AI crawlers, and the content is in the HTML (not only in JS).
