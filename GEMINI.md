# Total.js skills

Knowledge for writing Total.js 5 (total5) applications.

Before you create, edit or review code in a Total.js project, read `skills/totaljs-cookbook/SKILL.md` and then the reference files it points to in `skills/totaljs-cookbook/references/`. The whole cookbook in one file is `COOKBOOK.md`.

Total.js is a global/singleton framework, not Express or Nest. Follow the cookbook over habits from other frameworks.

Repository map and editing rules: `AGENTS.md`.
